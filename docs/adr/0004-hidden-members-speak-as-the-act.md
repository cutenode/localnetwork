# Hidden members speak as the act

Everyone in a booking thread can see the author DID of each message, so a hidden member answering an inquiry would reveal who's behind the act. When a hidden member writes in a booking thread, the site writes the message into the thread as the root account, labelled with the act's name, and keeps who actually wrote it in the act's space, where the act's members and staff can see it. Public members write their own messages as before.

## Considered options

- Answering reveals the member to that promoter, with a warning first: simpler, but it leaks the alias to everyone the act talks to.
- Requiring a visible manager to handle bookings for acts with hidden members: rules out solo anonymous aliases.
