# Planner

A private planner (saved DJs, from a DJ's profile or a project's page, and shows with working lineups) in a personal space on the promoter's own PDS. Inquiring from a planner show fills the inquiry in from the show's details and names the planner show in the inquiry (`plannerShow`), read back from the promoter's own planner rather than taken from the form. The thread links back to it for the promoter only, and the planner show opens the booking for each act it already asked.
