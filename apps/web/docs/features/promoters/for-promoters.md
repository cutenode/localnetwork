# For promoters

`/for/promoters` makes the case for booking DJs here, with the Find DJs search at the top. It shows a real listing from the directory and the matcher's real shortlist for that listing's sound near its city, both streamed so the page paints first, then example booking and planner screens (those are private, so the data is made up and marked as an example), press kits, and how to turn on the promoter section.
