# Calendar

`/dashboard/calendar` lists every night for the year ahead by month: shows announced for your acts, bookings with a date that are still live, and a promoter's planned shows. Unsettled ones have a dashed date, and when an act of yours has two or more unconfirmed bookings on one night the first says so. A booking that became a show counts once. Each source can fail alone, and the page says when some nights are missing. It's behind the `dashboardCalendar` release flag: while that's off for someone, the sidebar leaves Calendar out and the page answers 404.
