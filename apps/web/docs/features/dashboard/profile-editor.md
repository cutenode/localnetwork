# The profile editor

People edit their profile at `/dashboard/profile`: the basics, and the DJ and promoter sections they turn on, each adding its own fields (the project form is built from the same basics and performer fields). Turning a section off asks first, since saving deletes what was in it. The profile goes to the account's own repo with its session, over the version the form opened on. A session from before profiles is offered "Sign in again" when the page opens. Someone without a profile makes one from the first step of the checklist on `/dashboard`, from their Bluesky name and picture, read once from their own repo. The sections decide the dashboard sidebar: a DJ's projects under Yours, and for a promoter a Promoter section with Book DJs (`/dashboard/promoter`: the Find DJs search, Match a show, the inquiries they sent and their planned shows) and the planner. Until there's a profile, the planner and List a project show anyway, and projects someone manages always do. Saving the profile with the promoter section newly on points to Book DJs. On a phone the sidebar's main items become tabs along the bottom, and Menu opens the rest in a sheet.
