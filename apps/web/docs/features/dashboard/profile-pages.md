# Profile pages

Every account has a profile page at `/@<handle>`, showing its `computer.localnetwork.profile`: its basics (with the pronouns from its Bluesky profile, else the ones the profile kept from before), the performer and promoter sections it turned on, the DJ stats and sets it publishes, and the active projects it manages. A DID with a verified handle, and a handle in any other form, redirect there; an account without a verified handle has its page at `/@<did>`. Its sections are tabs (About, Mixes, Sets, How they play, Plays in), each a file in `src/lib/profile-tabs/` that the page collects, so a new tab is a new file; a tab with nothing in it is left out, and `?tab=<id>` opens one, without scripts too. An account without a profile record still gets a page, with its Bluesky display name when the directory keeps one (else its handle), the projects it plays in, and a line saying it hasn't set up a profile. An address that names no account is a 404. So is an account that's deactivated, taken down or suspended, whose page says only that the account isn't active, and a deleted account's page is a 410 saying it was deleted ([ADR 0020](../../../../../docs/adr/0020-inactive-accounts-are-asked-of-their-pds.md)). Handles across the site link to these pages. A profile with a record has a Follow button for everyone but its owner. The owner gets a Manage link to their profile editor, and staff one to its Find DJs listing (`/admin/listings/<did>`). A DJ Find DJs lists gets Send inquiry there, for everyone but themself, as an act's page has (Sign in to book when signed out).
